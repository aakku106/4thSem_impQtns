## About This Repository

This is an **unofficial** collection of study materials for 4th semester BSc.CSIT students. The content has been compiled by analyzing past papers and organizing topics that frequently appear in exams.

**Note:** This is not an official resource and should be used alongside your course materials, not as a replacement.

## What's Included

- Past question papers (2076-2081 + Model Questions)
- Subject-wise important questions
- 2-day emergency study plans
- Syllabus summaries

## 🆘 Last-Minute Emergency?

**Haven't studied and exam is in 2 days?** We've got a survival guide for you.

Our 2-day emergency plans cover the absolute minimum you need to know to have a chance at passing. These aren't ideal study methods, but if you're completely unprepared and the exam is tomorrow, these plans focus on:

- High-frequency exam topics only
- Quick revision notes
- Most repeated questions
- Basic concepts to get you through

**Reality check:** This won't get you top marks, but it might help you scrape through. Don't make this a habit.
